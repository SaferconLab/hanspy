# 第三章 可使用接口

## 3.3 脚本控制指令

### 3.3.1 HRIF_RunFunc
#### 描述：运行指定脚本函数。
##### 输入变量
| 输入变量名称 | 数据类型 | 有效范围 | 内容 |
|--------------|----------|----------|------|
| boxID | int | 0~5 | 电箱ID号，默认值=0 |
| strFuncName | string | - | 指定脚本函数名称，对应示教器界面的函数 |
| param | string | - | 参数列表 |
| result | list | - | 传入空列表，result=[] |

##### 输出变量
| 输入变量名称 | 数据类型 | 有效范围 | 内容 |
|--------------|----------|----------|------|
| result | list | - | 输出值 |

##### 返回值
| 返回值名称 | 数据类型 | 有效范围 | 内容 |
|------------|----------|----------|------|
| nRet | int | >0的整型值 | nRet=0:返回函数调用成功<br>nRet>0:返回调用失败的错误码 |

##### 示例
```python
# 指定运行函数Func_1
strFuncName="Func_1"
# 定义输入参数
param=[1,2,3]
# 定义返回值空列表
result=[]
# 运行函数Func_1
nRet=cps.HRIF_RunFunc(0,strFuncName,param,result)
```

### 3.4.19 HRIF_cdsSetIO
#### 描述：在运动指令到达目标点位前设置IO。
##### 输入变量
| 参数名称 | 数据类型 | 有效范围 | 内容 |
|----------|----------|----------|------|
| boxID | int | 0~5 | 电箱ID号，默认值=0 |
| rbtID | int | 0~5 | 机器人ID号，默认值=0 |
| nEndDOMask | int | - | EndDO0~EndDO7对应到nEndDOMask的bit0~bit7，如果某个bit是1，则其对应的EndDO的值需要更改，否则无需更改。 |
| nEndDOVal | int | - | EndDO0~EndDO7对应到nEndDOVal的bit0~bit7。0：低电平<br>1：高电平 |
| nBoxDOMask | int | - | BoxDO0~BoxDO7对应到nBoxDOMask的bit0~bit7，如果某个bit是1，则其对应的BoxDO的值需要更改，否则无需更改。 |
| nBoxDOVal | int | - | BoxDO0~BoxDO7对应到nBoxDOVal的bit0~bit7。0：低电平<br>1：高电平 |
| nBoxCOMask | int | - | BoxCO~BoxCO对应到nBoxCOMask的bit0~bit7，如果某个bit是1，则其对应的BoxCO的值需要更改，否则无需更改。 |
| nBoxCOVal | int | - | BoxCO~BoxCO对应到nBoxCOVal的bit0~bit7。0：低电平<br>1：高电平 |
| nBoxAOCH0_Mask | int | 0/1 | 0：无需更改<br>1：需要更改 |
| nBoxAOCH0_Mode | int | 1/2 | 1：电压模式<br>2：电流模式 |
| nBoxAOCH1_Mask | int | 0/1 | 0：无需更改<br>1：需要更改 |
| nBoxAOCH1_Mode | int | 1/2 | 1：电压模式<br>2：电流模式 |
| dbBoxAOCH0_Val | float | 0~20 | 电流模式:4-20mA<br>电压模式:0-10V |
| dbBoxAOCH1_Val | float | 0~20 | 电流模式:4-20mA<br>电压模式:0-10V |

##### 返回值
| 返回值名称 | 数据类型 | 有效范围 | 内容 |
|------------|----------|----------|------|
| nRet | int | >0的整型值 | 返回调用失败的错误码 |

##### 示例
```python
# 需要更改的EndDO按bit标识
nEndDOMask=1
# 各个需要更改的EndDO的目标状态
nEndDOVal=0
# 需要更改的BoxDO按bit标识
nBoxDOMask=0
# 各个需要更改的BoxDO的目标状态
nBoxDOVal=0
# 需要更改的BoxCO按bit标识
nBoxCOMask=0
# 各个需要更改的BoxCO的目标状态
nBoxCOVal=0
# BoxAOCH0是否需要更改的标识
nBoxAOCH0_Mask=0
# 模式
nBoxAOCH0_Mode=0
# BoxAOCH1是否需要更改的标识
nBoxAOCH1_Mask=0
# 模式
nBoxAOCH1_Mode=0
# 对应模拟量值
dbBoxAOCH0_Val=0
# 对应模拟量值
dbBoxAOCH1_Val=0
# 在运动指令到达目标点位前设置IO
nRet=cps.HRIF_cdsSetIO(0,0,nEndDOMask,nEndDOVal,nBoxDOMask,nBoxDOVal,nBoxCOMask,nBoxCOVal,
nBoxAOCH0_Mask,nBoxAOCH0_Mode,nBoxAOCH1_Mask,nBoxAOCH1_Mode,dbBoxAOCH0_Val,
dbBoxAOCH1_Val)

# 第三章 可使用接口

## 3.5 状态读取与设置指令

### 3.5.1 HRIF_SetOverride
#### 描述：设置速度比。
##### 输入变量
| 输入变量名称 | 数据类型 | 有效范围 | 内容 |
|--------------|----------|----------|------|
| boxID | int | 0~5 | 电箱ID号，默认值=0 |
| rbtID | int | 0~5 | 机器人ID号，默认值=0 |
| dOverride | float | 0.01~1 | 需要设置的速度比(0.01~1) |

##### 返回值
| 返回值名称 | 数据类型 | 有效范围 | 内容 |
|------------|----------|----------|------|
| nRet | int | >0的整型值 | nRet=0:返回函数调用成功<br>nRet>0:返回调用失败的错误码 |

##### 示例
```python
# 需要设置的速度比
dOverride=0.5
# 设置当前速度比
nRet=cps.HRIF_SetOverride(0,0,dOverride)
```

### 3.5.3 HRIF_SetPayload
#### 描述：设置当前负载参数。
##### 输入变量
| 输入变量名称 | 数据类型 | 有效范围 | 内容 |
|--------------|----------|----------|------|
| boxID | int | 0~5 | 电箱ID号，默认值=0 |
| rbtID | int | 0~5 | 机器人ID号，默认值=0 |
| dMass | float | 0~允许最大负载质量，范围为0到当前允许最大负载，单位[kg] | 质量 |
| dX | float | >0 | 质心X方向偏移,单位[mm] |
| dY | float | >0 | 质心Y方向偏移,单位[mm] |
| dZ | float | >0 | 质心Z方向偏移单位[mm] |

##### 返回值
| 返回值名称 | 数据类型 | 有效范围 | 内容 |
|------------|----------|----------|------|
| nRet | int | >0的整型值 | nRet=0:返回函数调用成功<br>nRet>0:返回调用失败的错误码 |

##### 示例
```python
# 需要设置负载质量
dMass=0.5
# 需要设置负载质心X方向偏移量
dX=0.5
# 需要设置负载质心Y方向偏移量
dY=0.5
# 需要设置负载质心Z方向偏移量
dZ=0.5
# 设置当前负载
```

### 3.5.4 HRIF_SetJointMaxVel

| dJ4 | float | 0~200 | J4轴最大速度，单位[°/s] |
| dJ5 | float | 0~200 | J5轴最大速度，单位[°/s] |
| dJ6 | float | 0~200 | J6轴最大速度，单位[°/s] |
| *注 | - | - | 关节速度有效范围需要参考具体机型。 |

| 返回值名称 | 数据类型 | 有效范围 | 内容 |

| nRet | int | >0的整型值 | nRet=0:返回函数调用成功<br>nRet>0:返回调用失败的错误码 |

| 返回值名称 | 数据类型 | 有效范围 | 内容 |

```python
# 定义需要设置的空间最小运动范围
```

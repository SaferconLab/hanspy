# 第三章 可使用接口

## 3.1 初始化

### 3.1.1 HRIF_Connect
#### 描述：连接机器人服务器。
##### 输入变量
| 输入变量名称 | 数据类型 | 有效范围 | 内容 |
|--------------|----------|----------|------|
| boxID | int | 0~5 | 电箱ID号，默认值=0 |
| IP | string | - | 控制器IP地址，根据实际设置的IP地址定义 |
| nPort | int | - | 控制器端口，一般为10003 |

##### 返回值
| 返回值名称 | 数据类型 | 有效范围 | 内容 |
|------------|----------|----------|------|
| nRet | int | >0的整型值 | nRet=0:函数调用成功<br>nRet>0:返回调用失败的错误码 |

##### 示例
```python
# 导入PythonSDK
from CPS import CPSClient
# 定义IP，端口
IP='192.168.0.10'
nPort=10003
# 创建对象
cps=CPSClient()
# 连接控制器
nRet=cps.HRIF_Connect(0,IP,nPort)
```
